# Play setup artwork

The assets in `public/assets/ui/play-setup/` were generated for Kings of the
Keep with OpenAI image generation. They are original, project-bound artwork;
the supplied UI mockup was used only as a composition and atmosphere reference.

- `battlefield.png` — text-free twilight battlefield and right-side keep with
  central negative space for the setup interface.
- `*-crossing.png`, `*-valley.png`, `*-dunes.png`, `river-crown.png`,
  `ashen-ridge.png`, and `four-kings-basin.png` — six text-free elevated
  strategy-map previews matching the current map data.
- `*-medallion.png` — four text-free painted faction emblems, displayed inside
  circular UI frames.

Generation prompts specified premium hand-painted strategy-game UI art, the
faction/map subject, no text or interface elements, and no logos or watermarks.
